pg-scraper

Really simple syndication, is really simple.

A simple program that generates a scraped RSS feed of Paul Graham's essays. My first project in Go; it was the perfect project to explore Go's concurrency model. It's deployed as a serverless function that generates the feed everytime a new request comes in.
